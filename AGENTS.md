# Personal Organizer - Agent Instructions

## Project goal

Build a simple personal task organizer in Python.

The application should allow a user to:

- add a task
- list tasks
- mark a task as completed
- assign a priority to a task

Tasks will be stored locally in a JSON file.

## Development rules

- Keep the project simple and easy to understand.
- Use Python.
- Keep compatibility with Python 3.9.
- Prefer the Python standard library.
- Do not add external dependencies unless they are really necessary.
- Do not use plugins or marketplace extensions.
- Explain important changes before making large modifications.
- Do not modify unrelated files.

## Agent architecture

This project will demonstrate:

- Codex as the main coding agent
- AGENTS.md for project instructions
- a custom Skill
- a custom MCP server
- a custom Subagent
