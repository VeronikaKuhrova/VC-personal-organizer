# Task Organizer Skill

Use this skill when working with tasks in the Personal Organizer project.

## Priority rules

Classify tasks using these rules:

- high: urgent tasks, deadlines, important submissions, or tasks blocking other work
- medium: important tasks that should be completed soon but are not urgent
- low: optional, routine, or non-urgent tasks

## Behaviour

When helping with task organization:

1. Prefer clear and short task titles.
2. Suggest a priority if the user did not provide one.
3. Do not change an existing priority unless there is a clear reason.
4. Keep completed tasks marked as completed.
5. If several tasks exist, recommend doing high-priority tasks first.

## Example

Task:
"Submit Vibe Coding assignment tomorrow"

Recommended priority:
high
